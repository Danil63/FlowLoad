Как строится нагрузка

      
    

    
k6 запускается на вашем компьютере и отправляет HTTP-запросы к API выбранного окружения. Браузеры для этих тестов не открываются.

    
Виртуальные пользователи

    
VU — независимый исполнитель сценария, а не отдельный аккаунт. 100 VUs не означают 100 запросов в секунду: скорость зависит от времени ответа API, числа запросов и пауз. При нехватке токенов одна сессия используется несколькими VUs.

    
    

      
Сценарий
Каждый VU проходит выбранные методы по порядку, затем делает паузу и повторяет цепочку.
Метод 1 → Метод 2 → Метод 3 → Пауза → Повтор

      
Профиль нагрузки
Методы выполняются параллельно отдельными группами VUs. Значения на графике складываются: 20 VUs на один метод и 30 на другой дают целевой максимум 50 VUs. Это не последовательный пользовательский путь.

    

    
Пауза между итерациями по умолчанию — 1 секунда (THINK_TIME_SECONDS). Чем дольше ответы, тем меньше итераций успевает выполнить каждый VU.

    
Перед запуском: проверьте адрес окружения, токены и суммарное число VUs. Изменяющие данные методы требуют отдельного разрешения; без него они пропускаются. Начинайте с небольшой нагрузки, особенно в production.

Формат файла токенов

      
    

    
Обычный текстовый файл tokens.txt в кодировке UTF-8, размером до 1 МБ. На каждой строке только значение одного токена.

    
# Замените строки ниже своими токенами
SESSION_TOKEN_VALUE_1
SESSION_TOKEN_VALUE_2
SESSION_TOKEN_VALUE_3

    
Это условные значения, не действующие токены.

    
    
      
  • Не добавляйте имя cookie, префикс Bearer, кавычки или точку с запятой.
    • 
      
  • Копируйте значение целиком, сохраняя символы и кодирование, например %2B и %3D.
    • 
      
  • Пустые строки и строки, начинающиеся с #, пропускаются. Повторы удаляются.
    • 
      
  • JSON, таблицы и экспорт состояния браузера не подходят.
    • 
    

    
Импорт заменяет текущий набор токенов. Файл сохраняется локально. Не добавляйте его в репозиторий и не передавайте посторонним.

    
Успешный импорт означает сохранение, а не проверку срока действия токенов.

  
  
    

      
Невалидные токены

      
    

    
API отклонил эти токены с кодом 401. Замените их и повторите проверку.

    
Номера соответствуют сохранённому набору после удаления повторов и пустых строк. Значения скрыты частично.
