# FlowLoad

Локальная утилита нагрузочного тестирования API на k6: окружения, импорт Swagger/OpenAPI, визуальные сценарии, распределение VUs по методам и HTML-отчёты на русском.

## Запуск на macOS

```bash
git clone https://github.com/Danil63/FlowLoad.git
cd FlowLoad
make start
```

Первый запуск устанавливает зависимости и открывает `http://127.0.0.1:8787/`. В дальнейшем используйте `make web`. Если порт занят, откройте уже работающий интерфейс либо остановите предыдущий сервер. Другой порт: `UI_PORT=8790 make web`.

## Порядок работы

1. **Окружение:** создайте проект с адресом API или выберите ранее созданный.
2. **Токен:** добавьте токены вручную или файлом. Ручной ввод дополняет набор без дублей; импорт файла заменяет его. Проверка запускается отдельно.
3. **Сценарии:** импортируйте JSON/YAML или публичную ссылку, выберите методы и соберите последовательность. Сохраните сценарий.
4. **Нагрузка:** выберите сценарий, настройте VUs для методов и сохраните профиль либо запустите последовательный сценарий. Справа от «Запустить» есть подсказка с диаграммой.
5. **Отчёты:** изучите ошибки, проверки и задержки до увеличения нагрузки.

Токены, документы, методы, сценарии, профили и отчёты разделены по окружениям. Одновременно выполняется один тест на локальном генераторе. Данные остаются на компьютере и исключены из Git; браузерные черновики сохраняются отдельно для каждого окружения.

Swagger UI по `/docs` поддерживается через попытку загрузки `/docs-json`. Импорт URL ограничен публичными IPv4-адресами, 15 секундами и 5 МБ. При VPN/DNS с непубличными адресами используйте файл.

## Важные ограничения

Шаблон «Критический путь» и проверка токенов пока адаптированы к игровому API, а не к произвольной бизнес-логике. Параметры запросов и зависимости между ответами требуют настройки. Сценарий выполняет методы последовательно, профиль запускает группы VUs по методам параллельно. Изменяющие данные запросы требуют отдельного разрешения.

Не добавляйте в Git токены, `.env`, дампы сессий и отчёты. Не запускайте большую нагрузку на production без согласования.
